Example evidence chain:

```text
BFS
├─ practice corpus → prior judge repositories / classmate graph sets
├─ from scratch    → include/bts/graph.hpp
├─ experiment      → labs/graph_traversal/main.cpp
├─ explanation     → docs/interview/bfs-dfs.md

```

The rule is **one artifact, one job**: judge repositories preserve repetition and failed attempts;
this repository preserves implementation/mechanism evidence.
