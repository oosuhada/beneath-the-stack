# Naming decision

Ten available names were checked against the `oosuhada` GitHub account before repository creation.

| Candidate | Read | Decision |
| --- | --- | --- |
| `beneath-the-stack` | product stack → machine stack; compact and memorable | **selected** |
| `beyond-the-browser` | strong narrative, but broader and less technical | finalist |
| `systems-under-the-hood` | accurate but tutorial-like and long | reject |
| `from-web-to-metal` | clear transition, slightly slogan-like | finalist |
| `computer-inside-out` | playful but less aligned with existing naming | reject |
| `under-the-browser` | too narrowly tied to frontend | reject |
| `machine-room-lab` | evocative, but does not signal CS/data structures | reject |
| `stack-to-silicon` | memorable, but overstates current hardware scope | reject |
| `systems-playground` | generic and common educational naming | reject |
| `core-mechanics-lab` | sounds like mechanical engineering | reject |

`beneath-the-stack` fits the project because “stack” has two useful meanings here: the application
technology stack already familiar from product work, and the deeper stack of runtime, OS, network,
storage and machine behavior underneath it.
